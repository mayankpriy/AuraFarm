# 🤝 Contributing to Aura Farming

Thank you for your interest in contributing to **Aura Farming 🌱**

This project is a **data debugging and learning toolkit**. Contributions should focus on improving examples, datasets, and explanations.

---

# 🚀 Getting Started (Step-by-Step)

## 🔹 Option 1: Using Git (Recommended)

```bash
git clone https://github.com/mayankpriy/AuraFarm.git
cd AuraFarm
```

---

## 🔹 Option 2: Using GitHub Desktop

1. Open GitHub Desktop
2. Click **File → Clone Repository**
3. Paste:

   ```
   https://github.com/mayankpriy/AuraFarm.git
   ```
4. Choose a local folder
5. Click **Clone**

---

# 🌿 Contribution Workflow (Follow Strictly)

### 1. Create a New Branch

```bash
git checkout -b feature/your-feature-name
```

❗ Do NOT work directly on `main` branch

---

### 2. Make Your Changes

You can:

* Add new debugging examples
* Improve existing code
* Add datasets
* Fix incorrect outputs

---

### 3. Add Changes

```bash
git add .
```

---

### 4. Commit Changes

```bash
git commit -m "Add: short description of your change"
```

Example:

```bash
git commit -m "Add: CSV null value debugging example"
```

---

### 5. Push to GitHub

```bash
git push origin feature/your-feature-name
```

---

### 6. Create Pull Request

* Go to GitHub repo
* Click **Compare & Pull Request**
* Fill all required fields
* Submit PR

---

# 📂 Contribution Types

You can contribute by:

* 📊 Adding CSV debugging examples
* 🗄️ Writing MySQL validation queries
* 📘 Improving explanations in notebooks
* 🧪 Adding real-world datasets
* 🔧 Fixing incorrect examples

---

# 📏 Rules (Must Follow)

* ✅ Code must run without errors
* ✅ No hardcoded file paths
* ✅ Use project folder structure
* ✅ Keep code clean and readable
* ✅ Add explanation where needed

---

# 📊 Data Rules

* ❌ Do NOT upload sensitive/private data
* ✅ Use open datasets (Kaggle, public sources)
* ✅ Keep dataset size reasonable

---

# 🧪 Testing (Before PR)

Before submitting:

* Run notebook end-to-end
* Verify output
* Ensure no errors

---

# 🚫 Common Mistakes to Avoid

* ❌ Editing directly on `main` branch
* ❌ Uploading large unnecessary files
* ❌ Missing explanations
* ❌ Broken or untested code

---

# 💬 Need Help?

* Use **Discussions** → for questions
* Use **Issues** → for reporting problems

---

# 🌟 Code Style

* Python → basic PEP8
* SQL → clean and readable
* Keep logic simple

---

# ❤️ Final Note

Aura Farming is a **learning-first project**.

Keep contributions:

* Clear
* Practical
* Easy to understand

---

Thank you for helping grow Aura Farming 🌱
