# 🌱 Aura Farming – Data Debugging & Learning Toolkit

Aura Farming is an open-source project designed to help engineers **debug, validate, and understand real-world data issues** using CSV files and MySQL.

This repository acts as a **practical handbook** with examples, datasets, and reusable code snippets.

---

## 🚀 Why Aura Farming?

In real-world data systems, you often face:

* Missing or null values
* Duplicate records
* Data mismatches
* Incorrect formatting
* Broken pipelines

Aura Farming helps you **identify, analyze, and fix these issues step-by-step**.

---

## 🔧 What You’ll Find Here

* 📂 CSV debugging using Python (Pandas)
* 🗄️ MySQL queries for data validation
* 🔍 Finding nulls, duplicates, and mismatches
* 🔁 Comparing datasets (CSV ↔ Database)
* 🧹 Data cleaning techniques
* 📊 Event-based datasets for real-world practice

## 🚀 Getting Started

```bash
git clone https://github.com/mayankpriy/AuraFarm.git
cd AuraFarm
```

---

```bash
pip install -r requirements.txt
```

---
